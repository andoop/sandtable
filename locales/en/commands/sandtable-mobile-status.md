View Sandtable mobile sync status (read-only).

Execute:
1. Run `scripts/sandtable-mobile-status.sh`.
2. Report: whether the server is running, the feature, the 4-digit code, paired, expiresAt, publicUrl.
3. If the server is not running, suggest `/sandtable-mobile-start`.
